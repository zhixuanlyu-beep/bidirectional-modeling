# 按自主计算成本枚举架构

`computation_search` 是显式导入的实验模块。候选答案是事先固定的程序和初态，通过无外界干预的计算满足完整有限目标。它落实“证据继承，失败架构不享有继续存在的特权”：每轮搜索从声明语言重新生成候选，不接收旧方案作为默认结构，也不将失败方案局部打补丁作为唯一搜索空间。已有残差商分析仍用于研究单个模型的行为等价；它不要求后续方案继承原模型。

实验、反例、证明约束可以保留，但它们有不同的证明范围。已知证据不相容可以否定绑定的候选，不能自动定位其中哪一条规则有错。当前模块保留具体程序、输入、输出、期望和证据来源；不从失败推断整个结构族失败，不根据共用材料传播排除。已有 `ExperimentHypothesisSearch.learn_conflict` 可以在自己的响应宇宙中独立证明承诺冲突；它的证书不能直接移入这里当作剪枝理由。

## 运行

```bash
PYTHONPATH=src python3 -m bidirectional_modeling.cli computation-demo --json
```

```python
from bidirectional_modeling.computation_search import (
    FiniteBitTask, BitEvidence, search_computations, verify_computation_certificate,
)

task = FiniteBitTask('二输入 AND / 精确有限规格', 2, (0, 0, 0, 1))
evidence = (
    BitEvidence((0, 0), 0, '实验记录:00'),
    BitEvidence((1, 1), 1, '实验记录:11'),
)
result = search_computations(task, evidence, max_cost=9)
assert result.status == 'found'
assert result.certificate.cost == 9
assert result.exhausted_through == 8
review = verify_computation_certificate(task, evidence, result.certificate)
assert review.status == 'valid'
assert review.optimality == 'verified'
```

两条证据允许两个投影 `y=x₀`、`y=x₁`，但完整的四输入规格分别在 `10`、`01` 否定它们。通过的程序为 `input:0, input:1, and, halt`，成本是装载 4、执行 4、输出 1。找到一个最优代表不证明表达形式唯一；交换两个输入可得到同成本的另一个代表。

`FiniteBitTask.outputs` 按 `00, 01, 10, 11` 等字典序声明全部输入的精确输出，宽度 0 时输入只有 `()`。证据是另外提供的实验信息，需要来源，不从候选预测生成。证据必须处于规格域且与规格一致；冲突输入声明被拒绝，不冒充架构反例。应用范围和校准约定写入 `scope` 并参与绑定。真实实验是否可靠仍由调用方负责。

## 固定机器与资源模型

机器使用有限位栈，代码和初始栈都是不可变数据；无 Python 回调、外部查询、隐藏宏、任意精度常量或免费候选模块。

| 指令 | 行为 |
| --- | --- |
| `zero / one / input:i` | 压入常量位或固定输入的第 i 位；i 必须小于声明宽度 |
| `not / and / or / xor` | 对栈顶一位或两位作固定布尔运算 |
| `drop / dup` | 删除或复制栈顶一位 |
| `halt` | 结束并输出唯一剩余位，须是末尾指令 |
| `again` | 内部重置栈和程序计数器，继续计算；须是末尾指令 |

声明检查逐项确认栈深度，末尾须恰好剩一位。`again` 没有结束路径，提供一个确实会无限运行、却可以做有限预算实验的候选。它不会产生反例；在更高预算层仍会被重新枚举。

计费固定为：装载每个指令字和初始位各 1 单位，每条执行指令 1 单位，输出位 1 单位。内部重置还对删除的栈位和恢复的初始位逐位计费。预算在装载、执行、重置或输出任一阶段不足，都返回 `resource_limit`，输出保持 `None`。这是固定抽象机器的成本，输入宽度和输入获取是共享任务背景；不声称等于 Python 墙钟时间、底层 CPU 指令数或 Kolmogorov 复杂度。

可终止程序有 L 个指令和 D 个初始位，成本恰为

\[
C= (L+D)+L+1=2L+D+1.
\]

所以预算 B 限制 L 和 D，指令字母表在固定输入宽度下有限，每层可以有效穷尽。即使结果预置在初态中，也按位装载；删去未使用数据不返还成本。保证来自这个明确的计费与语言限制，不来自“λ 演算必然展开全部初始结构”。本语言中运行成本与长度有关，但优化指标包含初态、执行和输出，不能用已有 `DescriptionLength.total` 或自报 `ModelMetrics.complexity` 替代。

所有有限布尔函数都可以在该语言中表达，但这里的最优性只相对于这一语言、输入约定和计费。它不是通用 λ 演算枚举，也不推广到任意程序或无限输入域。顺序程序的完整运行成本与输入无关；未来增加分支、压缩或新的原语，必须重做资源下界、覆盖论证并升级语言身份域。

## 搜索、证据与验收

搜索由预算 0 逐层扩展至 `max_cost`，每层重新枚举可落在该资源层的程序与初态，先检查活跃证据，再逐项检查完整规格。语义不符只生成具体反例；资源不足和解释器错误不能作为语义失败。

| 结果 | 含义 |
| --- | --- |
| `found` | 非空完整有限输入域全部通过，证书绑定语言、规格、证据来源、程序和实际成本；更低成本层已经完成 |
| `absent_within_bound` | 完成了截至 `max_cost` 的有限层，没有该预算内完整解；不排除更高成本的解 |
| `unknown` | 搜索试验额度用尽或解释器错误；`exhausted_through` 仅报告此前完成的预算层 |

`max_cost` 是单个候选在单个输入上的总成本上限；规格成本取完整输入域上的最大值。`max_trials` 则限制候选试验数，每次试验最多执行证据数加规格输入数个运行。它不约束候选构造、枚举、哈希、总内存或墙钟时间。每次调用重新生成并验收，不存储结构特权或跨调用排除缓存。

只要存在有限成本的解，在没有额外搜索试验截断且解释器正常的情况下，它必落入某个有限层；该层中只有有限多个有界实验，故可以找到并验收。一个无限执行候选只耗尽当前运行额度，不阻塞下一候选。有限规格穷尽提供的是本问题类的完整验收；它不能替代无限问题类的数学证明或判定器。

反例记录属于本次报告，保留其中的程序、输入、值及来源可用于后续实验。来源变更、证据撤回或范围变更后，旧证书失去绑定，应使用新活跃证据重新搜索和复核。撤回并不证明旧架构正确，新增反例也不授权把单个失败永久推广到整个模型族。

## 独立复核与最优性

`verify_computation_certificate` 不调用搜索器或搜索验收助手。它从当前原始规格执行见证，核对完整输出和真实成本，然后重新枚举成本严格更低的整个有限层，直接执行并比较规格。证据先与规格校验，再核对其有序内容及来源绑定。

`status=valid` 只说明完整目标见证已复核；`optimality=verified` 还要求更低成本层完成。发现更低成本见证时 `optimality=refuted`；复核额度耗尽或错误时为 `undecided`。复核过程中已经验证的完整目标见证可以保留，不能把未完成的最优性检查标记为通过。零复核额度连见证也未执行，返回 `status=undecided`。

枚举器、机器执行、Python 运行时、规范编码和规格声明仍是共同信任基础；这里没有宣称完全独立的证明内核。测试通过小布尔真值表和普通栈参照检查执行、已知四种一输入函数的最优成本、每个试验截点、错误注入和证据失效。`absent_within_bound` 目前是搜索器的穷尽结果，没有另行序列化的不存在证书。

## 按需局部理论提示

可选 `hints` 接受有序基础程序，按层与原枚举交错执行；每个基础候选前最多一次提示试验，不删除基础路径。提示仍接受完整目标，可能消耗额外试验预算。`extensions.local_theories` 按精确作用域/宽度提供提示，并单独验证局部覆盖与整体提取。见[局部理论与覆盖](local_theories.md)；覆盖与单对翻译保持成本均不代替独立的最优性复核。
