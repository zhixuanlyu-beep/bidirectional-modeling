# 核心契约（修订 4）

结论只对绑定的有限声明、协议、活跃证据与预算负责。本文集中规定何时可以发布结论；[版本政策](version_policy.md)规定接口和归档怎样演进。[契约映射](core_contracts.json)将每项契约连接到生产模块、文档及具体回归，`tools/check_contracts.py` 检查映射是否完整、引用是否仍存在。检查引用不能证明测试充分，语义修改仍需审查独立参照和截断行为。

## 结论发布条件

| 契约 | 可以发布的条件 | 必须保持未决或限制主张的情况 |
| --- | --- | --- |
| C-PASS：满足性通过 | `complete`、非空已验证场景、全部需求通过；覆盖来自框架枚举或调用方完整清单；规范、模型声明、情境、轨迹批次与成本上限均绑定当前输入 | 无法确认模型身份、空场景、未完成覆盖、需求错误、声明漂移或必需探针无完成结果。一个完整场景不能代替完整场景域 |
| C-EXCLUDE：排除 | 完整、绑定的失败评估，或已知候选预测与有效活跃观测直接不符；冲突传播额外要求证据单独相容、承诺单独相容、二者合取不相容，且目标候选包含全部失败承诺 | 执行异常、未知预测、相似名称、共用材料或父子关系不能构成排除。证据自身矛盾只说明声明内数据不相容，不能学习经验冲突 |
| C-FOUND：存在 | 在声明响应域或指定候选域内找到具体见证；独立复核其成员资格、约束、证据及查询绑定 | 见证的名称或求解器成功标志不足以证明存在。见证成立不要求穷尽其他候选；它不证明满足性、唯一性或最小性 |
| C-ABSENT：不存在 | 在绑定的非空有限响应域、完整候选目录或显式低阶目录中完成穷尽，并通过复核；查询记录说明所查的域 | 截断、取消、未知预测、目标预测未知或未声明低阶参照类都阻止相应不存在证明。空低阶参照类为 UNKNOWN；空相容目录的宏观异义查询可以 ABSENT，但元数据为 `compatible_catalogue_nonempty=False` |
| C-UNIQUE：唯一性 | 搜索 `determined` 要求至少一个相容候选、没有未决候选、全部相容候选宏观答案相同；目的解释要求有效接受集合只有一项且候选生成完整 | 宏观答案唯一不等于结构候选唯一。找不到其他答案但相容目录为空，不能建立答案。未知替代、候选生成异常或精确预算截点上无法确认迭代器结束，均阻止唯一性 |
| C-UNDECIDED：未决与资源 | 错误、取消和截断通过状态及诊断显式传播；已经完整复核的局部见证可以保留，未完成部分不能升级结论 | 操作额度与模拟额度分别记账。回调已启动而消耗不可靠时预留剩余模拟额度。操作预算不约束构造、哈希、内存或墙钟时间 |
| C-LIVE：活跃依赖与撤回 | 使用证书前重验协议、当前证据（包括来源）及承诺；证据替换先验证后原子更新；情境迁移验证关系并在目标域重证 | 撤回或来源替换使失去支持的旧证书失效；中断替换保持原会话。证据历史、缓存命中和说明图不能继续授权排除；改变目录使宏观问题绑定改变 |
| C-SUFFICIENCY：充分性与最小性 | 保留观测足以确定当前非空目录的单一宏观答案时，可发布充分性；最小基数或最小成本主张额外要求对应有限优化完成及复核 | 保留的证据失效、未知候选、空目录或多答案不能证明充分性。充分、不可再删、基数最小与成本最小分别陈述 |
| C-REPLAY：声明与重放 | 有序数据、已知格式及身份域，完整的有限模型表、用例清单、协议、目标、观测、版本与预算；重新生成预测并核对原会话，复核活跃证书 | 校验和只检查一致性。外部 Python 回调、闭包及服务配置不能由 JSON 重建；格式不认识时明确拒绝并要求重生成，不猜测补字段。重放 verified 指本次有限归档核验完成，不自动等于通过或唯一 |
| C-COMPUTATION：有限成本最优架构 | 固定有限指令语言，候选代码、初态装载、执行和输出全部计费；每个资源层有效有限枚举，完整非空有限输入规格全部通过；复核见证并穷尽严格更低成本层 | 已知样例相容不等于完整目标；资源不足不构成语义反例；试验或复核截断阻止不存在与最优性。最优不等于唯一，不推广到任意程序、无限问题类或机器墙钟时间 |
| C-ABSTRACTION：任务判断与操作保持 | 非空明确有限域、满射抽象与完整表；全部判断因子化，全部声明操作保持抽象结果和可适用性；明确声明范围完整，正因子表由原表逐项复核 | 无操作时仅证明静态判断；截断或范围不完整阻止通过，真实成对反例仍可重放。目的归属不替代证明；通过不推出方案成功、最粗划分、无限反馈性质或求解方法完备 |
| C-LOCAL：局部理论与提取 | 局部程序通过全部声明输入、重叠输出一致、联合域覆盖完整有限任务并符合独立目标，提取程序逐项通过且成本实测；证书重放原始声明 | 局部成立不等于目标成立或原最优候选已覆盖；单对翻译成本保持不等于全体覆盖；资源截断保持未决。搜索提示不得删除基础候选或替代最优性检查 |

## 最小复核逻辑与信任范围

查询复核的业务逻辑位于 `_query_review.py`：按原始行检查观测，按原始允许行检查承诺，逐项检查目录成员及宏观答案。FOUND 直接检查见证；ABSENT 枚举其声明域。`verify_query_result` 核对形状、域与指纹，既不调用查询生成器，也不读索引或调用内证据快照。错误注入同时破坏生成匹配器、索引、过滤入口，检查复核是否仍能拒绝错误回执。

仍需信任 Python 执行、类型校验、规范编码与哈希、预算计数以及输入声明。冲突生成和冲突复核仍共享 `_has_world` 等扫描规则；满足性、闭合和残差也有共享执行基础，不能声称整个证明链已完全独立。测试中的集合真值表、有限状态机、独立路径模拟是额外参照，覆盖范围由夹具限定。有限表新增 81 个二状态偏转移表 × 15 条长度至 3 的动作路径，参照仅用普通索引更新，不调用模型模拟器。

自主计算的证书复核不调用搜索器或其验收助手，但共享有限语言枚举、机器解释器及结构编码。对完整目标的直接检查和更低成本层检查分别报告；证据来源、撤回和范围变化使旧绑定失效。有限层保证及计费见[自主计算搜索](autonomous_computation.md)。先前失败架构不构成新候选的默认结构，也不构成新约束的证明。

任务抽象的复核直接读取具体表，检查证书中的宏观因子，不调用分析器的代表构造。生成与复核仍共享声明校验、索引约定及编码；成对比较参照覆盖二状态有限表。[语义委托](semantic_delegation.md)区分规格细化和模型细化，[有限任务抽象](task_abstraction.md)说明范围、操作与检查额度。这里的判断充分性与 C-SUFFICIENCY 的“观测足以确定目录答案”分别陈述。

未来 SAT/SMT 后端通过 `SearchQueryBackend` 交付候选见证或证明材料。当前可接受的规则仍是直接检查见证、有限穷尽复核不存在；没有实现特定证明格式的检查器前，求解器的 UNSAT 标志不能绕过这些规则。若穷尽复核超预算，接受状态保持未决，即使生成后端已返回 ABSENT。

## 修改与发布检查

语义修改先列出受影响契约，再更新映射中的对应测试和边界文档；新回归归入原契约，只有新增独立主张时才增加契约编号。调整操作数量可以改变某预算下能完成的工作，但不能改变完整有限域的真值，也不能使截断成为反证。

发布软件前先收敛未发布的模型声明绑定、证据快照、独立复核与有限表归档；检查同名换模型、过期失败、撤回来源、错误注入、全部预算截点、跨进程固定归档及 wheel。性能改动需同时核对语义和总成本。按职责去除重复业务规则；独立复核的少量重复属于刻意保留的参照，不能为消除重复而重新委托生成器。
