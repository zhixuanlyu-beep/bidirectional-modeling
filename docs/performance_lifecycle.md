# 完整使用成本与规模边界

原操作基准继续检测重复扫描；`benchmarks/lifecycle_costs.py` 补充实际生命周期。固定阶梯是 3/10/34 个审批候选（每模型 3 状态、4 动作、3 用例、8 响应行），以及 8/64/512/4096 行响应域的首行见证与穷尽不存在；scan、indexed 分别冷启动。审批工作负载包含三轮撤回/换来源/重验，共六次证据更新。

```bash
PYTHONPATH=src python benchmarks/lifecycle_costs.py > /tmp/lifecycle-costs.json
```

各阶段单独测量构造、指纹、双轮预测准备、会话初始化、搜索、查询、独立复核、证据替换与重验、归档和新模型重放。归档 API 自身重新准备预测，重放又重新执行预测，因此总时间包含三次准备流程，不能把此总时间当作一次普通查询的开销。外部观测使用夹具，未计传感器、业务系统或人工采集延迟。

内存是 tracemalloc 的 Python 分配；报告各阶段相对开始时存量的新增峰值及存量变化，包含仍被先前阶段保留的对象影响，不是进程 RSS。跟踪会影响计时；当前是单次诊断样本，不是统计显著的速度比较或 CI 耗时门槛。操作计数仍不包含全部 Python 构造/哈希指令。脚本要求独占 tracemalloc，并在完成或异常后停止跟踪。

## 当前测量与选择

完整机器信息和明细保存于 [诊断样本](../benchmarks/lifecycle_costs_sample.json)。本次 Python 3.12.14 / Linux、每阶段一百万操作上限得到：

| 候选数 | scan 全流程秒 | indexed 全流程秒 | scan 双轮预测秒 | indexed 双轮预测秒 | 完成情况 |
| ---: | ---: | ---: | ---: | ---: | --- |
| 3 | 0.414 | 0.402 | 0.120 | 0.113 | 两者全部完成 |
| 10 | 1.268 | 1.251 | 0.385 | 0.378 | 两者全部完成 |
| 34 | 4.244 | 4.233 | 1.336 | 1.312 | 两者全部完成 |

此样本中查询及冲突复核较小，准备预测是主要可见成本，差异不足以选择新索引或符号后端。4096 行首行见证在 scan 只检查一个候选行；冷 indexed 先支付全域建索引，约 0.020 秒，对照 scan 查询约 0.00022 秒。4096 行不存在的独立复核两者都检查 4096 行，约 0.030 秒；索引不能减少这一信任边界内的穷尽工作。这些数值只说明此机器和此工作负载，不作为普遍倍数承诺。

`lifecycle_costs_sample.json` 另保存相同 4096 行、100 操作上限的截断结果。首行见证的 scan 可以完成，必须穷尽的查询和冷索引返回 unknown，复核保持 undecided。有限声明能够构造不保证指定预算下能完成证明。更大的世界、响应列、动作路径或候选目录尚未测量，不能外推当前可完成范围。

## 如何据测量决定下一步

先用实际应用数据重跑相同阶梯，再扩大最明显的维度，并记录完成状态、截断原因及准备/复核所占成本。重复证据筛选占主导时评估增量索引；大部分成本来自模型准备时评估增量预测或更小的受控用例；显式响应宇宙无法构造时才评估符号候选后端及其证明检查规则。

响应域可能随列数指数增长，位集合不解决构造这一域的成本。当前操作预算是协作式语义预算，不能保证构造、哈希、序列化、内存或墙钟截止。应用须先限制声明规模、输入大小与用例长度；需要硬限制时用独立进程和外部资源限制，中止视为未决。没有完整计时任务时，脚本记录 undecided 和已经发生的耗时，不把部分耗时计为完成速度。

## 自主计算与局部理论的准备开销

两位 AND 完整规格、`00→0` 与 `11→1` 两条证据、搜索上限 9、默认基础枚举的固定夹具：

| 操作 | 精简前 | 当前 |
| --- | ---: | ---: |
| 搜索构造完整输入表 | 590 | 1 |
| 独立复核构造完整输入表 | 158 | 1 |
| 搜索执行位栈程序 | 886 | 836 |
| 独立复核执行位栈程序 | 274 | 274 |
| 一次局部覆盖生成及复核临时构造查询库 | 2 | 0 |
| 搜索候选试验数 | 589 | 589 |

证据先按二进制输入对应的规格表位置核验。生成阶段一次准备有序检查清单，先检查带来源的证据，再检查其余完整域输入；同一个输入不再因为既是证据又是规格而重复运行。独立复核仍直接重放完整目标，并在整个复核调用内复用完整输入表，不调用生成验收器。局部声明校验与索引构造分离，只有实际建立查询库时才生成索引。`test_computation_work_simplification` 固定准备次数、无重复执行和独立重放边界。

这些计数是此夹具下的准备及解释器调用次数，不是统一时间复杂度或墙钟加速倍数。机器计费、候选枚举顺序、证据来源、证书格式和预算未决规则不变。
