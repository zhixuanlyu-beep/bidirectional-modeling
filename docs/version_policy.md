# 接口、证书和会话的版本政策

当前发行元数据仍为 `0.36.0`，CHANGELOG 的“未发布”描述当前源码变化。本次不发布软件、不改发行版本。稳定范围先以[核心契约](core_contracts.md)及本次验证的有限入口为准；新有限表和重放入口为实验 API，待真实应用评估后再扩大兼容承诺。

## 三条独立版本线

| 对象 | 当前版本与范围 | 演进规则 | 迁移规则 |
| --- | --- | --- | --- |
| Python API | `0.36.0` 发行；声明、满足性、有限查询、预测适配与 `search_session.SearchSession` 是本轮稳定候选 | `0.y.z` 阶段补丁用于保守修复；字段增删、签名、导入位置及结论含义的破坏性变化提升 y 并给前后用法。进入 1.x 后按 SemVer：破坏提升主版本，兼容新增提升次版本 | 在 CHANGELOG 和所影响契约中注明迁移。顶层 `__all__` 和各模块明确公开的入口承担接口承诺；下划线内部工具、派生索引及操作数量不承担兼容承诺 |
| 证书身份域 | 满足性 `satisfaction-evaluator-v3`；情境 `context-v2`；观测 `observed-model-v3`；轨迹 `trace-batch-v3`；模型声明 `model-declaration-v1`；有限搜索协议 v1、带目标表的问题 v2、查询 v1 | 改变任何绑定内容、顺序、规范编码或主张含义时升级相应域；格式标识与包版本独立。未改变身份或证明含义的内部优化不升级域 | 不重新包装旧证明为新证明。保存原材料，以当前规则重新采集或验证。迁移回执必须明确旧域、新域与重新验证结果。当前不存在通用证书 JSON schema，不能把上述身份域当作一个统一序列化版本 |
| 会话数据 | `schema_version=2`；读写只支持 2 | 兼容可选审计字段可保持 schema；新增必需语义、删除字段、改变表示或校验和算法提升 schema | 仅当旧材料足以恢复相同语义时实现显式升级并提供固定夹具。缺失目标映射、模型声明或证据时要求重新适配；不允许无声推断。未知 schema（包括当前不支持的 1）明确拒绝 |

新 `finite-model-table-v1`、有限模型 `schema_version=1` 与重放包 `schema_version=1` 是另外两种受控数据格式。`versions.py` 集中声明会话和重放所需的版本号及身份域清单；它不是全部模块格式的自动迁移注册表。

`computation_search` 同样是显式导入的实验 API，不改变既有搜索目录、会话或满足性证书。计算证书绑定 `autonomous-bit-stack-v1` 语言与成本语义；规格及证据指纹分别使用 `task-v1`、`computation-evidence-v1`。新增原语、计费或输入背景时升级语言身份，不能复用旧最优性结论。当前计算回执仅提供 Python 数据对象与 JSON 演示输出，未提供长期归档读取器。

`task_abstraction` 是新增显式导入的实验 API，绑定域 `finite-task-abstraction-v1`。判断列、环境范围、投影、操作语义、覆盖声明及假设都参与身份；更改这些材料需重新生成和复核。当前仅支持 Python 数据对象及 JSON 演示，没有通用证书归档读取器，也不改变满足性证书、会话 schema 或残差商的保证。

`extensions.local_theories` 是显式导入的实验 API，绑定域 `local-bit-theory-v1` 与 `local-bit-cover-v1`；局部来源、范围、有序清单、见证和实测成本必须重验。`search_computations` 的可选 `hints` 只改变同层发现顺序及试验消耗，不改变机器、目标验收或计算证书格式。覆盖证书没有最优性主张或长期归档读取器。

## 收敛当前未发布改动

| 改动 | 兼容影响 | 必需动作 |
| --- | --- | --- |
| 满足性证书增加必填模型声明身份，协议升至 v3 | 旧满足性证书不能完整绑定当前模型，旧构造参数不兼容 | 按[证书迁移](certificate_migration.md)重新生成，不以模型名补字段 |
| 适配声明加入实例 simulate 和资源指标 | 旧适配来源摘要不足以表示当前声明 | 双轮重新适配并更新会话来源；搜索协议和冲突身份域未改 |
| 单调用证据快照与对应批次公共检查 | 内部优化；持久化格式不变 | 独立复核仍读原声明；证据替换不保留调用快照 |
| 查询独立复核规则 | 完整结果与指纹不变；复核实现及操作开销可变化 | 旧有限查询回执仍按绑定和原声明重验；错误或超预算保持未决 |
| 有限表及重放包 | 新模块显式导入；已有会话 schema 不变 | 使用 v1 数据格式，保存版本及预算；旧回调会话继续只是离散搜索声明归档 |

本轮可稳定的语义包括有限证明域、非空通过、明确未决、活跃依赖、事务式撤回及直接见证复核。操作计数、缓存布局、性能倍数、自动模型重构、开放世界完备性及外部回调的永久行为均不在稳定承诺中。

## 长期重放与迁移验证

受控归档的包版本是审计信息；读取器依据模型、重放、会话和身份域版本决定是否可解释。已知域下每次重新执行有限表、比较问题及批次绑定，再复核保存的冲突。未知域需从原始声明明确重生成新归档，不能仅修改版本号和校验和。语义相同的未来读取器应继续读取固定 v1 夹具；格式演进应保留旧夹具测试或明确宣布不兼容并给迁移步骤。

当前已验证多个进程与哈希种子，并将固定归档放入 Python 3.9/3.11/3.13 的 CI 测试。修改 producer 元数据不改变已知格式的解释。尚未运行未来发行二进制，不能据此宣称任意跨版本兼容；固定夹具是以后验证此承诺的依据。
