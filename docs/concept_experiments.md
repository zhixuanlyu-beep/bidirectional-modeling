# 概念、区分实验与排除边界

覆盖到代码行只说明路径被执行。下面为关键概念指定可区分的输入、预期证书及排除边界；表中的实验名对应 `tests/test_concept_contracts.py` 的测试类/方法。结论限于声明的有限域，测试通过不等于所有可能实现均已证明正确。

| 概念主张 | 区分实验 | 应有证书/结果 | 排除边界 |
| --- | --- | --- | --- |
| 聚合方式具有不同含义 | AggregationContracts：轨迹 8→2→12→7；初值、终值、最小、最大、均值、变化量分别为 8、7、2、12、7.25、−1；逐项增加 1 构造失败条件 | 原要求完整通过；偏移要求完整失败，记录实际观测值 | 只反驳该要求；不反驳其他聚合方式 |
| EACH 约束每个时刻 | EACH ≥2 通过，EACH ≥3 失败，FINAL ≥3 通过 | 中间时刻构成失败见证 | 最终值通过不能替代全程条件 |
| 未声明数值归一化时类型有意义 | 数值 1 属于 (1,)，不属于 (True,)；相等与不等保持一致 | 完整确定性结果 | 不以 Python 的隐式类型相等扩大相容范围 |
| 对应失败需要成功观察到不一致 | CorrespondenceContracts：正确求和投影与偏移 +1 投影对照 | verified 对照 refuted；反例保留场景、时间步和两侧/投影快照 | 仅否定绑定的对应关系及实验情境 |
| 异常不是行为反例 | 场景投影抛异常 | undecided；diagnostics 非空，counterexamples 为空，commutes=None | 不能进入反例排除锥 |
| 接口不适用不是执行反证 | 投影只返回未声明字段 | not_applicable；applicability_failures 非空 | 应修正接口声明/适配，不能由此排除行为候选 |
| 缺乏覆盖不能证明交换 | 单次验证和套件在预算 1 下中断 | 未决；未启动用例 commutes=None | 不由“暂未看到冲突”推出通过 |
| 联合冲突只排除完整继承者 | ExclusionConeContracts：u、v 单独满足观测，u∧v 与观测冲突；三个候选共享材料 | 只剪除 joint，保留 u 和 v | 材料相同、共享单个承诺均不足以继承反例 |
| 排除依赖活跃证据与协议 | 撤回必要观测、改变来源标签、改变协议 scope | 旧冲突复核失败；撤回后 joint 可重新进入相容集 | 禁止永久缓存旧排除锥 |
| 目标自相矛盾不算经验反证 | 原协议 C 可满足且与观测冲突；目标 C 的满足集为空 | 迁移 not_applicable，target_contradiction_not_established | 保留目标约束自身一致性检查，禁止盲目复制旧证书 |
| 展示必须保留语义状态 | PresentationContracts：向真实 CLI 注入未决对应 | JSON 显示 undecided、null commutes；文本显示“未决”；不查询未创建的已验证路径 | 没有已验证路径不能伪造通过，也不能导致演示崩溃 |

资源指标和规格绑定的变更实验另见 `tests/test_failure_paths.py` 中 `EvidenceFailureTests`；它们验证修改声明后旧批次失效，重新采集后才可重新验证。

## 冲突证书及排除锥

在固定协议 P 的有限响应域 W 中，观测 E 与承诺 K 的经验冲突要求：

- 观测单独可满足：W_E 非空；
- 承诺单独可满足：W_K 非空；
- 二者联合不可满足：W_E ∩ W_K 为空。

证书保存协议绑定、联合承诺核心与必要观测。只有继承完整 K 的候选，才属于该证书在当前活跃证据下的排除锥。联合核心中的某一个承诺不应单独承担全部失败；材料、名称或代码父子关系不构成反例继承依据。证据撤回或来源/协议变化后，必须复核或重证。

## 对应模块的状态

- `verified`：完整覆盖、绑定有效、接口适用且没有不交换见证。
- `refuted`：在适用范围内成功观察到不交换见证。
- `undecided`：执行异常、覆盖不足或绑定无法保持。
- `not_applicable`：声明的接口或场景映射不适用。

诊断优先于适用性失败，适用性失败优先于对完整声明的判定。混合情况下保留已有局部见证，但未决结果本身不是整项声明的可迁移反证。`commutes=False` 可以记录局部不交换见证；只有 `complete=True` 且 `commutes=True` 时 `passed=True`。

`CorrespondenceIssue` 保留定位信息，不作为行为反例。默认评估器保证 TraceBatch 只含合法 Trace；对应模块对异常自定义适配器的防御检查仍保留，不能仅因标准入口难以触达就判为冗余。

## 实验能否发现错误实现

运行 `python tools/check_concept_mutations.py`，脚本先验证原始实验，再在各自临时源码副本中注入十九种错误。其中六种是最小值变最大值、EACH 退化为 FINAL、联合承诺变任意交集、忽略证据撤回、跳过迁移目标重证、无反例即通过；另十三种执行、主张边界、证据流转与下述可选实验的错误见下文。

每种错误必须被相应断言检出；测试导入或运行错误不计为检出。源仓库不被改写。这是十九项有限的实验充分性回归，不是通用变异完备性证明。CI 将它与普通覆盖率分开执行。

CLI 的语义输出测试属于单元测试覆盖；打包后的命令运行与 JSON 格式验收仍单列。文档中的覆盖率不能替代上述概念主张和实验边界。

## 简化后的跨入口回归

`tests/test_review_simplification.py` 将同一语义在不同入口的表现并列检查：证书派生状态不可分离修改；空、截断或未绑定批次不能证明等价；不稳定组合回调只产生未决；可靠反驳默认停止残差工作；部分预测无需构造搜索目录；修改诊断文案不影响复核身份；普通导入和引擎创建不加载组合、残差或概念记忆服务。


`tests/test_execution_contracts.py` 增加以下区分实验：保持目标接受恒定轨迹而拒绝 1→0→1；终值目标不声称增加或减少；预算 1 下采集后异常不能再次执行候选；生成上限前不额外读取；生成中断保留已验证前缀；筛查升级失败保留缓存并继续其他候选；修改失败文案不改变协议身份，修改资源协议则改变绑定。变异检查另检出维持改终值、异常消耗漏记、越界读取及失败文案进入指纹四类错误。


`tests/test_claim_boundaries.py` 区分执行额度与留存场景、精确均值与舍入均值、原始规范与延时规范、人工概念关系与结构证明，并验证排除导出保留原声明。新增四项错误注入分别取消失败预算预留、舍入均值、默认启用额外验收，以及取消概念关系来源要求。


## 跨模块证据流转实验

`tests/test_evidence_lifecycle.py` 在既有公开入口之间验证下列对应关系，不增加新的领域模块或证书转换入口。

| 路径 | 实验变化 | 应保留的边界 |
|---|---|---|
| 解释 → 部分筛查 → 独立复核 | 相同的 0/1 承诺与观测 | 排除结论一致；解释审计记录与预测证书仍是不同对象 |
| 筛查 → 热缓存 → 撤回/替换来源 | 保留预测，撤回观测或更换来源标签 | 旧证书失效；新观测可复用预测并生成新排除记录 |
| 筛查 → 小预算复核 → 完整复核 | 中断采集、预算不足、取消，再以足够预算重试 | 未决不能升级为有效证书；部分匹配不能发布完整预测 |
| 局部预测 → 修改情境或候选 | 改变未执行实验的情境，或更换候选身份 | 声明绑定失效，不能把局部排除传播给另一个候选 |
| 冲突 → 迁移 → JSON 恢复 → 撤回 | 新协议重证后撤回目标证据 | 旧协议证书不能直接使用；撤回后目标排除锥消失 |
| 迁移 → 任意工作预算边界 | 从零到成功所需工作量逐一截断，包括已有部分重证结果时 | 返回未决且不发布半成品会话，源会话保持不变 |
| 扩大响应域 → 迁移 → JSON 恢复 | 旧冲突在新响应域不再成立 | 新会话不继承该证书，源证书仍仅属于原域 |

额外两项错误注入分别跳过排除证书的活跃观测依赖检查、让会话保留已撤销证书。相应端到端断言必须检出错误；运行失败不算检出。

这里的 0/1 只是声明的有限响应标签，来源标签也是调用方声明；这些测试不证明真实实验来源或无限域完备性。

## 可缩减的实验序列与可选探索

`tests/test_evidence_state_machine.py` 使用 Hypothesis 状态机生成并缩减证据替换、撤回、缓存筛查和预算中断的序列。每一步复核活跃证据的排除证书及失效边界；它检验操作组合，不给随机生成的世界附加概率语义。`hypothesis` 仅属于测试额外依赖。

| 任务 | 调用入口 | 可认证的主张 | 未决或无效边界 |
|---|---|---|---|
| 残差区分见证重放 | `residual.verify_distinguishing_context(report, witness, model, equivalence, context)` | 从报告声明的初态路径重放，到见证动作后确实有观察或动作支撑差异 | 预算、回调异常为未决；绑定、源微观状态或声明终值改变为无效。局部有效不推出整个残差商已完整或最小 |
| 经验冲突的承诺撤回 | `search_repairs.suggest_consistency_repairs(problem, commitments, evidence)`；`verify_consistency_repairs` | 在绑定响应域与证据上，冲突核有独立证书，另枚举并复核**全部基数最小**的撤回集合 | 证据或承诺单独矛盾时该任务不适用；预算截断的可行撤回不等于最小或全集 |
| 有限属性蕴涵 | `extensions.implications.check_implication(context, implication)`；`explore_implications`；`verify_implication_assessment` | 有属性对象可直接反驳；只有存在支持对象、扫描完成且调用方声明有限对象域完整时，才能在该域内验证 | 无支持、域未声明完整或扫描预算不足都未决；`source` 和完整性声明被指纹绑定，但不认证实际世界的来源与完备性 |

`explore_implications.exhaustive` 只指给定属性、前提长度和候选数量下的**提案枚举**是否完成；具体蕴涵的 `verified` 另取决于有限对象域的完整性和支持对象。两种穷尽范围不同，不能互推。上述三个变异实验分别模拟忽略源状态、遗漏另一个最小修复以及把无支持蕴涵误报为已验证。

### 与借鉴项目的对应范围

| 来源机制 | 本项目实际采用的部分 | 不可等同的部分 |
|---|---|---|
| [Hypothesis 状态机](https://hypothesis.readthedocs.io/en/latest/stateful.html) | 组合规则、操作后的不变量及失败序列缩减；撤回证据错误可缩减到“替换 → 筛查 → 撤回” | 生成实验不是穷尽证明，也不在运行时引入概率权重 |
| [AALpy 的 W-method oracle](https://github.com/DES-Lab/AALpy/blob/master/aalpy/oracles/WMethodEqOracle.py) | 从初态前缀重放动作，比较已声明的有限行为见证 | 这里比较同一模型的两状态；没有学习系统与假设机的等价查询，也没有 W-method 的转换覆盖和状态数上界保证 |
| [PySAT 的 MCS 枚举](https://pysathq.github.io/docs/html/api/examples/mcsls.html) | 把冲突证据与撤回承诺后的可满足性分开，保留多个修复见证 | PySAT 的 MCS 是**包含极小**；本项目只枚举**基数最小**撤回。例：撤回 `{B}` 或 `{A,C}` 都是包含极小，本项目只返回 `{B}`；也没有 SAT 编码或求解器 |
| [conexp-clj 属性探索](https://github.com/tomhanika/conexp-clj/blob/master/src/main/clojure/conexp/fca/exploration.clj) | 蕴涵须接受具体对象反例，已声明对象域外的事实不自动成立 | 本项目穷举有限提案，不执行专家确认、反例增补、背景知识闭包或典范蕴涵基；对无支持前提保守地标为未决，而形式概念分析允许真空成立的蕴涵 |

因此这些接口分别是本项目任务中的局部方法，不声称移植上述原算法。`tests/test_search_repairs.py` 用基数最小与包含极小的区分实例固定这一边界；`tests/test_implication_exploration.py` 检查即使提案枚举完毕，无支持蕴涵仍未决。
